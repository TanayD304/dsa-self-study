## Interview Revision

Simulate a Google interview.

Do not reteach.

Challenge my understanding.

---

# Section 1 — Active Recall

Ask me

* What is this pattern?
* Why does it exist?
* What problem does it solve?

Wait for my response.

Do not answer immediately.

---

# Section 2 — Recognition

Ask

How would you recognize this pattern within 30 seconds?

Prompt me for

* Keywords
* Constraints
* Input
* Expected complexity

Do not reveal the answer unless I struggle.

---

# Section 3 — Mental Model

Ask me to explain the intuition.

Examples

* Sliding window movement
* Pointer movement
* State transition
* Graph traversal
* Recursive thinking

Evaluate my explanation.

Improve only if necessary.

---

# Section 4 — Generic Template

Ask me to derive the generic algorithm.

Do not ask for full code immediately.

Instead ask

* Variables
* State
* Loop structure
* Decision logic

Only then move to code.

---

# Section 5 — Algorithm

Ask me to explain the complete algorithm.

Evaluate

* Missing steps
* Incorrect assumptions
* Logical gaps

Then provide corrections.

---

# Section 6 — Correctness

Ask

Why does this algorithm always work?

Challenge weak explanations.

Discuss

* Invariants
* Proof
* Correctness reasoning

---

# Section 7 — Complexity

Ask

* Time complexity
* Space complexity
* Why

Do not accept Big-O without reasoning.

---

# Section 8 — Edge Cases

Ask me to list important edge cases.

Then compare against the complete list.

---

# Section 9 — Common Mistakes

Quiz me.

Examples

* What mistakes are common?
* What bug did you make originally?
* How would you debug it?

---

# Section 10 — Mini Quiz

Generate five rapid-fire questions.

Examples

* Recognition
* Complexity
* Variants
* Edge cases
* Optimization

Wait for my answers.

---

# Section 11 — Coding Challenge

Provide one unseen interview problem.

Requirements

* Same pattern
* Medium or Hard
* No hints initially

Allow me to think.

Only provide hints if requested.

---

# Section 12 — Google Follow-up

After solving the problem ask

* Can you optimize memory?
* Can you improve readability?
* Can this work on streaming data?
* Multiple queries?
* Parallel execution?
* Dynamic updates?

---

# Section 13 — Related Patterns

Ask

Which other patterns are commonly confused with this one?

Discuss

* Differences
* Similarities
* Recognition signals

---

Based on my answers identify

* Knowledge gaps
* Weak concepts
* Confidence level
* Revision priority

Recommend actions.

* Keep explanations concise unless I request more detail.
