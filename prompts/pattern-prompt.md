# Objective

I am preparing for **Google Software Engineer II (L5)** interviews.

Act as a **Google L5 Software Engineer** mentoring another engineer.

Teach the following Data Structures & Algorithms pattern in a structured, interview-focused manner.

The goal is not to memorize problems.

The goal is to deeply understand the underlying pattern so I can recognize, derive, implement, optimize, and explain it during interviews.

Use **C++17** throughout.

Primary learning resource is **Striver's TUF+**.

Everything should be written in clean, professional Markdown.

Avoid unnecessary theory.

Optimize for interview performance.
