> *Pattern First • Engineering Mindset • Interview Ready*

## About

Welcome to my personal Data Structures & Algorithms knowledge base.

This repository documents my complete journey towards becoming a **Google Software Engineer II (L5)**.

Unlike traditional interview repositories that simply collect LeetCode solutions, this repository follows a **Pattern First** learning philosophy.

Every problem is treated as an application of an underlying algorithmic pattern rather than something to memorize.

The objective is not just to solve interview questions.

The objective is to become an engineer capable of solving unseen problems through reasoning, abstraction and reusable algorithmic thinking.

---

# Goals

By the end of this repository I aim to:

* Master every major DSA interview pattern.
* Build strong algorithmic intuition.
* Recognize patterns within 30 seconds.
* Write optimal C++ solutions from memory.
* Explain correctness and complexity confidently.
* Handle Google follow-up discussions.
* Build long-term engineering knowledge instead of temporary interview preparation.
