# Roadmap Philosophy

This roadmap is designed around **patterns**, not problems.

Each session teaches exactly **one interview pattern**.

A session is considered complete only when:

* Pattern understood
* Notes completed
* Generic template learned
* Foundation problems solved
* Google-level problems attempted
* Revision scheduled
* Git committed
