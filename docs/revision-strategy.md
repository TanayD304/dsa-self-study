# Revision Strategy

> **Learning is temporary. Revision creates mastery.**

---

# Purpose

The purpose of revision is **not** to reread notes.

The purpose is to transform knowledge from **short-term memory** into **long-term intuition**.

A pattern is considered mastered only when it can be:

* Recognized instantly
* Explained confidently
* Implemented without reference
* Applied to unseen problems
* Recalled months later

Learning ends when the session finishes.

Mastery begins with revision.

---

# Revision Philosophy

Most candidates solve a problem once and never revisit it.

A few weeks later, they remember the solution but not the underlying pattern.

This repository follows a different philosophy.

```text
Learn Once

↓

Revise Multiple Times

↓

Recognize Instantly

↓

Recall Naturally

↓

Master Forever
```

The objective is not to remember solutions.

The objective is to remember **thinking patterns**.

# Rev1 — Reinforcement

### Objective

Prevent forgetting.

### Duration

15–20 minutes

### Activities

* Read the one-page revision sheet.
* Recall the intuition.
* Explain the pattern aloud.
* Write the generic template from memory.
* Solve one easy or medium problem.

### Questions

Can I recognize this pattern immediately?

Can I explain why it works?

Can I derive the template without notes?

---

# Rev2 — Confidence Building

### Objective

Reduce dependency on notes.

### Duration

20–30 minutes

### Activities

* Do not open notes initially.
* Recall everything from memory.
* Solve one medium problem.
* Review mistakes from Session Day.

### Questions

Can I derive the algorithm?

Can I explain correctness?

Would I recognize this in an interview?

---

# Rev3 — Independence

### Objective

Become interview-ready.

### Duration

30–45 minutes

### Activities

* Solve one unseen problem.
* Explain the solution aloud.
* Write code without referring to notes.
* Compare with previous mistakes.

### Questions

Can I solve without hints?

Can I defend the complexity?

Would I pass a Google interview for this pattern?

---

# Interview Revision

This is the highest level of revision.

Treat every revision as a mock interview.

Rules

* No notes
* No internet
* No editor assistance
* 40-minute timer
* Think aloud

Workflow

```text
Read Problem

↓

Recognize Pattern

↓

Explain Brute Force

↓

Optimize

↓

Code

↓

Dry Run

↓

Complexity

↓

Follow-up Questions
```

---

# Long-Term Review

Every month, revisit completed patterns.

Objectives

* Prevent forgetting
* Refresh intuition
* Update confidence
* Review mistakes
* Solve one random problem

The session should take no longer than 10–15 minutes.

---

# What to Revise

Never reread everything.

Revise only what matters.

Priority order

1. Recognition
2. Intuition
3. Generic Template
4. Algorithm

# Confidence Scale

Every revision updates the confidence level.

| Level | Meaning               |
| ----- | --------------------- |
| 🔴    | Don't understand      |
| 🟠    | Need notes            |
| 🟡    | Can solve with hints  |
| 🟢    | Independent           |
| ⭐     | Can teach confidently |

The objective is to move every session toward ⭐.

# Mistake Review

During every revision ask

* What mistake did I make originally?
* Why did I make it?
* What signal did I miss?
* How will I avoid it next time?

Document every lesson.

Mistakes become revision assets.

---

# When Confidence Drops

Sometimes a revision exposes forgotten concepts.

If confidence drops from 🟢 to 🟠:

Do not continue.

Return to

* Intuition
* Recognition
* Generic Template

Then repeat the revision.

# Monthly Mastery Audit

At the end of every month ask:

Can I still recognize every completed pattern?

Can I still write the template?

Can I still explain correctness?

Can I solve an unseen medium problem?

Can I teach the pattern?

If the answer is "No", restart the revision cycle.

---

# Session Completion Criteria

A session is **not complete** after solving problems.

A session is complete only after:

* Session completed
* Rev1 completed
* Rev2 completed
* Rev3 completed
* Interview revision completed
* Confidence = 🟢 or ⭐

Until then, it remains part of the active revision queue.

---

# Revision Priority

When time is limited, revise in this order:

1. 🔴 Sessions
2. 🟠 Sessions
3. Recently learned sessions
4. Frequently used interview patterns
5. Oldest completed sessions

Never spend equal time on every topic.

Prioritize weaknesses.

---

# Interview Week Strategy

One week before interviews

Daily routine

* 2 Pattern revisions
* 2 Medium problems
* 1 Hard problem
* 1 Mock interview
* 15-minute mistake review

Avoid learning completely new patterns.

Focus on recall and confidence.

# Golden Rules

* Never skip revisions.
* Never reread everything.
* Recall before reading.
* Recognition is more important than implementation.
* Review mistakes every time.
* Confidence must improve after every revision.
* Weak patterns deserve more attention than strong ones.
* Revision creates mastery.

---

# Final Goal

The purpose of revision is not to remember yesterday's solution.

The purpose is to ensure that six months later, when an interviewer presents an unfamiliar problem, your brain naturally recognizes the underlying pattern and derives the solution with confidence.

> **Patterns fade without revision. Mastery is built through deliberate recall, spaced repetition, and continuous refinement.**
